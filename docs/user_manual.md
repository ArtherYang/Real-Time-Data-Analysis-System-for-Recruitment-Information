## 2 注册与登录

### 2.1 注册账号

1. 打开系统首页，点击右上角 **"登录/注册"** 按钮
2. 在表单中填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 邮箱 | 用于登录和找回密码 | `zhangsan@example.com` |
| 手机号 | 备用登录方式 | `13800138000` |
| 密码 | 8-20 位，需包含字母和数字 | `Abc12345` |
| 昵称 | 系统显示名称 | `张三` |

3. 点击 **"注册"** 按钮
4. 注册成功后自动登录，进入 Dashboard

> **注意**：邮箱和手机号至少填写一项；密码不能为纯数字或纯字母。

### 2.2 登录

1. 点击右上角 **"登录/注册"** 按钮
2. 在登录表单中输入：
   - **账号**：邮箱 或 手机号
   - **密码**：注册时设置的密码
3. 点击 **"登录"** 按钮
4. 登录成功后跳转 Dashboard

### 2.3 登录安全

- 连续输入错误密码 **5 次**，账号将被锁定 **15 分钟**
- 登录成功后，Token 有效期为 **24 小时**
- 如 Token 过期，系统会自动尝试刷新；刷新失败则需重新登录

### 2.4 退出登录

点击右上角用户头像 → **"退出登录"**。

## 3 Dashboard 看板

Dashboard 是系统核心页面，登录后默认展示。页面从上到下分为四个区域：

### 3.1 顶部操作栏

- **数据导出**：点击右上角导出按钮，可选择导出 **CSV** 或 **Excel** 格式
- **筛选面板**：设置全局筛选条件，影响所有图表

### 3.2 KPI 统计卡片（第一行）

四个数字卡片实时展示：

| 卡片 | 含义 |
|------|------|
| 📊 有效岗位总数 | 当前系统中状态为"有效"的全部岗位数 |
| 🆕 本周新增 | 最近 7 天内采集的新岗位数 |
| 💰 平均最低薪资 | 所有岗位 salary_min 的均值（排除面议） |
| 💰 平均最高薪资 | 所有岗位 salary_max 的均值（排除面议） |

### 3.3 图表区

| 位置 | 图表 | 说明 |
|------|------|------|
| 第二行 | 🔥 热门岗位分类 | 按 job_category 聚合的岗位数量排行，横向柱状图 |
| 第二行 | 🏙️ 城市分布 | 各城市岗位数量，支持 Top N 筛选，条形图 |
| 第三行 | 💰 薪资分布 | 按分类/城市/经验/学历分组，展示均值/中位数/分位数，柱状图带误差线 |
| 第四行 | 🎓 经验要求分布 | 饼图展示经验要求占比 |
| 第四行 | 📚 学历要求分布 | 饼图展示学历要求占比 |
| 第五行 | ☁️ 技能词云 | 出现频率最高的技能标签，字号越大越热门 |
| 第五行 | 📈 薪资趋势 | 时间维度上的薪资变化折线图 |

### 3.4 数据更新

- Dashboard 数据来自后端 `/api/v1/analysis/*` 接口
- 分析结果有 **1 小时缓存**，相同筛选条件下不重复计算
- 如需刷新，切换筛选条件或等待缓存过期

## 4 筛选岗位

### 4.1 筛选面板

Dashboard 顶部的筛选面板支持以下维度：

| 筛选维度 | 类型 | 说明 | 示例 |
|---------|------|------|------|
| 城市 | 下拉选择 | 精确匹配工作城市 | 北京 / 上海 / 深圳 |
| 岗位分类 | 下拉选择 | 精确匹配岗位大类 | 技术 / 产品 / 运营 |
| 行业 | 下拉选择 | 精确匹配所属行业 | 互联网 / 金融 / 教育 |
| 经验要求 | 下拉选择 | 精确匹配经验要求 | 应届生 / 1-3年 / 3-5年 |
| 学历要求 | 下拉选择 | 精确匹配学历要求 | 大专 / 本科 / 硕士 |
| 来源平台 | 下拉选择 | 精确匹配数据来源 | BOSS直聘 / 前程无忧 |
| 日期范围 | 日期选择器 | 筛选发布日期范围 | 2026-06-01 ~ 2026-07-01 |

### 4.2 岗位搜索

在导航栏进入 **"岗位搜索"** 页面：

1. 在搜索框中输入**关键词**（如 "Python"、"数据分析"）
2. 关键词会在**岗位名称**和**技能标签**中进行模糊匹配
3. 可组合使用左侧筛选面板缩小范围
4. 搜索结果以列表形式展示，包含：岗位名、公司、城市、薪资范围、经验要求、学历要求

### 4.3 岗位详情

点击搜索结果中的任意岗位卡片，可查看详细信息：

- 岗位描述原文
- 福利标签（五险一金、年终奖等）
- 公司信息（规模、类型）
- 数据来源平台
- 发布日期

## 5 分析页面

导航栏提供三个专项分析入口：

### 5.1 薪资分析

路径：导航栏 → **"薪资分析"**

- **薪资分布图**：按指定维度（分类/城市/经验/学历）展示薪资均值、中位数、P25/P75 分位数
- **经验-薪资矩阵**：交叉展示不同经验级别和岗位分类的薪资水平

### 5.2 城市分析

路径：导航栏 → **"城市分析"**

- **城市岗位分布**：Top N 城市岗位数量排行
- **CR5 集中度**：Top 5 城市岗位占总量百分比
- **省份聚合**：按省份汇总的下钻数据

### 5.3 技能分析

路径：导航栏 → **"技能分析"**

- **技能词云**：最热技能可视化（字号 = 出现频率）
- **技能共现分析**：哪些技能经常同时出现（如 Python + SQL）
- **分类技能排行**：每个岗位大类下最需要的 Top N 技能

## 6 数据导出

### 6.1 CSV 导出

1. 在 Dashboard 或分析页面设置好筛选条件
2. 点击右上角 **"导出"** 按钮
3. 选择 **"CSV"** 格式
4. 浏览器自动下载 `.csv` 文件（UTF-8 BOM 编码，Excel 可直接打开）

**导出字段**：岗位名称、公司、城市、最低薪资、最高薪资、薪资类型、经验要求、学历要求、岗位分类、技能标签、数据来源、发布日期、公司类型、公司规模、福利

### 6.2 Excel 导出

1. 操作步骤同 CSV 导出
2. 选择 **"Excel"** 格式
3. 下载带样式的 `.xlsx` 文件：
   - 蓝色表头 + 白色字体
   - 自动列宽
   - 首行冻结
   - 自动筛选器

### 6.3 注意事项

- 导出数据量受当前筛选条件限制
- 导出的薪资为原始数据（元），不做转换
- 面议岗位在导出时会保留，薪资字段为空

## 7 常见问题（FAQ）

### Q1: 注册时提示"该邮箱已被注册"
**A**: 该邮箱已在系统中注册。请使用其他邮箱，或使用该邮箱直接登录。如忘记密码，请联系管理员。

### Q2: 登录时提示"账号已被锁定，请X分钟后重试"
**A**: 连续输入错误密码超过5次，账号已自动锁定15分钟。请等待锁定时间过后再试。

### Q3: Dashboard 数据为空
**A**: 可能原因：
1. 数据库中暂无数据（需先执行采集任务）
2. 筛选条件过于严格，导致无匹配结果
3. 后端服务异常（检查 `docker compose ps` 确认服务状态）

### Q4: 图表加载缓慢
**A**: 分析数据有 1 小时缓存。首次请求需要实时计算，较慢（3-5 秒）；后续相同参数的请求命中缓存，毫秒级响应。

### Q5: 如何查看系统运行状态
**A**: 
- API 健康检查：`http://localhost/health`
- 监控面板：`http://localhost:3001`（Grafana，默认账号 admin/admin）
- 容器状态：终端执行 `docker compose ps`

### Q6: 如何重启系统
**A**: 
```bash
cd recruitment-analytics
docker compose down
docker compose up -d
```
